# Quick SEO & Indexing Checklist

1. Verify the site with Google Search Console (add the meta verification code to `index.html` where indicated).
2. Submit the sitemap: https://utilitybillhelp.github.io/bristolwestbillpay/sitemap.xml
3. Ensure the GitHub Pages settings publish the `main` branch and use the site URL.
4. Test structured data with Google's Rich Results Test.
5. Run Lighthouse and address Core Web Vitals issues (LCP, CLS, FID/INP).

Helpful links and commands
- Preview locally: `python3 -m http.server 8000`
- Validate sitemap: https://validator.w3.org/

Suggested next steps
- Add analytics (privacy-compliant) and verify domain ownership.
- Consider short, top-level content improvements for high-intent keywords (headline and first paragraph) and keep FAQ answers precise.
